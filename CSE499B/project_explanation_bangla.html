CSE499B সিনিয়র প্রজেক্ট

১. প্রজেক্টের পরিচয়

এই প্রজেক্টটি একটি Adaptive Hybrid Framework যা Large Language Models (LLMs) এর গাণিতিক সমস্যা সমাধানের ক্ষমতা উন্নত করে। এটি দুটি জনপ্রিয় reasoning strategy - Chain-of-Thought (CoT) এবং Tree-of-Thought (ToT) কে একসাথে ব্যবহার করে সবচেয়ে ভালো ফলাফল দেয়।

মূল উদ্ভাবন:

  • একটি Router Model যা স্বয়ংক্রিয়ভাবে সমস্যার কঠিনতা বিশ্লেষণ করে
  • সহজ সমস্যার জন্য দ্রুত CoT এবং কঠিন সমস্যার জন্য নির্ভুল ToT ব্যবহার করে
  • সময় এবং computational cost উভয়ই কমিয়ে accuracy বজায় রাখে

২. সমস্যা কী ছিল?

বর্তমান সিস্টেমের সমস্যা:

Chain-of-Thought (CoT):

  • ✅ খুব দ্রুত কাজ করে (০.৮ সেকেন্ড)
  • ✅ কম token ব্যবহার করে (৫০টি)
  • ❌ কঠিন সমস্যায় ভুল উত্তর দেয় (৭২% accuracy)

Tree-of-Thought (ToT):

  • ✅ খুব নির্ভুল উত্তর দেয় (৮৯% accuracy)
  • ✅ জটিল সমস্যা ভালোভাবে সমাধান করে
  • ❌ অনেক সময় নেয় (৪.২ সেকেন্ড)
  • ❌ অনেক বেশি token খরচ হয় (৩২০টি)

মূল সমস্যা: সব সমস্যার জন্য একটাই strategy ব্যবহার করা অদক্ষ। সহজ সমস্যায় ToT ব্যবহার করলে সময় ও টাকা নষ্ট হয়, আবার কঠিন সমস্যায় CoT ব্যবহার করলে ভুল উত্তর আসে।

৩. আমার সমাধান

Adaptive Hybrid System:

আমার সিস্টেম একটি Machine Learning-based Router Model ব্যবহার করে যা:

  • প্রতিটি সমস্যা বিশ্লেষণ করে (সমস্যার দৈর্ঘ্য, keyword, operation দেখে)
  • সমস্যাকে "Easy" বা "Hard" হিসেবে classify করে
  • Easy সমস্যার জন্য CoT select করে (দ্রুত)
  • Hard সমস্যার জন্য ToT select করে (নির্ভুল)

৪. সিস্টেম কীভাবে কাজ করে?

ধাপ ১: ব্যবহারকারী একটি গাণিতিক সমস্যা দেয়
ধাপ ২: Preprocessing Module সমস্যা বিশ্লেষণ করে (feature extraction)
ধাপ ৩: Router Model সিদ্ধান্ত নেয় - Easy নাকি Hard?
ধাপ ৪: Easy হলে CoT Engine, Hard হলে Smart ToT Engine ব্যবহার হয়
ধাপ ৫: LLM reasoning generate করে এবং উত্তর বের করে
ধাপ ৬: Answer Validation Module উত্তর যাচাই করে
ধাপ ৭: চূড়ান্ত উত্তর output হিসেবে দেওয়া হয়

৫. উদাহরণ দিয়ে ব্যাখ্যা

উদাহরণ ১: সহজ সমস্যা (CoT নির্বাচিত)

সমস্যা: "সারার কাছে ৫টি আপেল আছে। সে আরো ৩টি কিনলো। এখন তার কাছে কতটি আপেল আছে?"

Router এর সিদ্ধান্ত: Easy সমস্যা → CoT ব্যবহার করবে

CoT Reasoning:

  • ➤ ধাপ ১: শুরুতে আপেল = ৫টি
  • ➤ ধাপ ২: নতুন কিনলো = ৩টি
  • ➤ ধাপ ৩: মোট = ৫ + ৩ = ৮টি

ফলাফল: উত্তর = ৮টি আপেল | সময় = ০.৮ সেকেন্ড | Token = ৪৫

উদাহরণ ২: কঠিন সমস্যা (ToT নির্বাচিত)

সমস্যা: "একটি দোকানে ২৪টি আপেল আছে। সকালে ১/৩ অংশ এবং বিকালে বাকি অংশের ১/৪ অংশ বিক্রি হলো। কতটি আপেল অবশিষ্ট আছে?"

Router এর সিদ্ধান্ত: Medium-Hard সমস্যা → ToT ব্যবহার করবে

ToT Reasoning (Multiple Branches):

  • Branch 1: সকাল: ২৪ × ১/৩ = ৮, বাকি = ১৬
  • Branch 2: বিকাল: ১৬ × ১/৪ = ৪, বাকি = ১২ ✓
  • Branch 3: যাচাই: ২৪ - ৮ - ৪ = ১২ ✓

ফলাফল: উত্তর = ১২টি আপেল | সময় = ১.৫ সেকেন্ড | Token = ১২০
