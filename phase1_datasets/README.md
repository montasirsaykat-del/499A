# Phase 1 Datasets

This folder contains all datasets needed for CAMR Phase 1 evaluation.

## Files Required
- gsm8k_test.csv
- mgsm_en.csv
- mgsm_de.csv
- mgsm_es.csv
- mgsm_bn.csv
- svamp_test.csv
- math_test.csv
- logiqa_test.csv
- strategyqa.csv
- run_phase1.py

## How to Run
1. Download all files from this folder
2. Put them in same directory
3. Run: python run_phase1.py
